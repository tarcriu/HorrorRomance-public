# Horror/Romance

Horror/Romance is a slasher dating sim created by AleGotic12 and her team, Vital Bones, using the Ren'Py engine. We're a team of Latino developers, writers, and artists trying to create an entertaining and interesting story.

Unfortunately, we lost access to our old repository, created by our programmer VMiracle. As a solution, we've decided to make a fork in order to keep everything neatly organized and continue working on our updates after Chapter 3.
